# Project Overview

## Business Problem

A coffee business needs a clear way to monitor sales performance, compare products, understand revenue trends, and review payment behavior.

## Objective

Build an interactive Power BI dashboard that converts coffee-sales data into useful business insights.

## Project Workflow

1. Load and inspect the source data
2. Clean and transform the data
3. Build the Power BI data model
4. Create revenue and target measures
5. Analyze product-level performance
6. Analyze monthly and date-wise revenue trends
7. Review payment-method behavior
8. Present the findings through interactive dashboard pages

## Dashboard Structure

- **HOME**
- **REVENUE**
- **ABOUT US**

## Business Value

The report can support:
- Revenue monitoring
- Product-performance comparison
- Target tracking
- Trend identification
- Better sales decisions
